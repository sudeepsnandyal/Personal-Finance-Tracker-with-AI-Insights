\# 💰 FinTrack AI — Personal Finance Tracker



A full-stack Personal Finance Tracker with AI-powered insights.



\## 🚀 Tech Stack

\- \*\*Frontend:\*\* HTML5, CSS3, JavaScript, Chart.js

\- \*\*Backend:\*\* Java 17, Spring Boot 3.2

\- \*\*Security:\*\* JWT Authentication, BCrypt

\- \*\*Database:\*\* MySQL 8

\- \*\*AI:\*\* Groq API (Llama 3.1) — Free



\## ✨ Features

\- ✅ User Signup/Login with JWT

\- ✅ Income Management

\- ✅ Expense Tracking with Auto-Categorization

\- ✅ Budget Planning with Alerts

\- ✅ Dashboard with Charts (Pie, Bar, Line)

\- ✅ AI Financial Advisor (Groq)

\- ✅ Expense Prediction



\## ⚙️ Setup Instructions



\### 1. Clone the Repository

git clone https://github.com/YOUR\_USERNAME/finance-tracker-ai.git



\### 2. Setup MySQL

CREATE DATABASE finance\_tracker\_v2;



\### 3. Configure application.properties

cp src/main/resources/application.properties.example

&#x20;  src/main/resources/application.properties



Fill in your MySQL password and Groq API key.



\### 4. Run

Right click FinanceTrackerApplication.java

→ Run As → Spring Boot App



\### 5. Open

http://localhost:8080
